Política de privacidade

Última atualização: 15 de outubro de 2026.

O Hermes Gmail Monitor é uma ferramenta pessoal usada somente pelo seu dono, Manoel Calixto, na conta Google dele.

Dados acessados

A ferramenta usa a permissão gmail.readonly para ler o remetente, o assunto, a data e o trecho inicial dos e-mails novos da caixa de entrada. Ela não envia, apaga, arquiva nem altera e-mails.

Como os dados são usados

Esses dados servem só para identificar e-mails importantes e avisar o dono. O remetente, o assunto e o trecho dos e-mails novos são enviados ao provedor de modelo de IA configurado no assistente Hermes do dono (atualmente a Anthropic) para classificação. Nenhum dado é vendido, compartilhado com terceiros para outros fins ou usado para publicidade.

Armazenamento

O token de acesso e um registro dos e-mails recentes (remetente, assunto, data e trecho) ficam apenas no computador do dono. Nenhum servidor da ferramenta armazena dados.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Privacy policy

Last updated: October 15, 2026.

Hermes Gmail Monitor is a personal tool used only by its owner, Manoel Calixto, on his own Google account.

Data accessed

The tool uses the gmail.readonly scope to read the sender, subject, date and snippet of new inbox messages. It never sends, deletes, archives or modifies email.

How data is used

This data is used only to identify important messages and alert the owner. The sender, subject and snippet of new messages are sent to the AI model provider configured in the owner's Hermes assistant (currently Anthropic) for classification. No data is sold, shared with third parties for other purposes, or used for advertising.

Storage

The access token and a log of recent messages (sender, subject, date and snippet) are stored only on the owner's computer. No server operated by the tool stores any data.

Revocation

Access can be revoked at any time at myaccount.google.com/permissions.

Limited use

Use and transfer of information received from Google APIs adhere to the Google API Services User Data Policy, including the Limited Use requirements.
